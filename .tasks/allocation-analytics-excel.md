# Allocation analytics Excel export

User approved a flat Excel layout and requested immediate year/unit query parameters. Query synchronization and full Excel export implemented. Builds/tests were not run.

Existing convention: frontend TableToolbarActions export button calls a web backend endpoint with arraybuffer response, then downloads an XLSX Blob. Backend export service validates permissions, collects domain data, and renders a JXLS template with jxls-poi. Examples: OvertimeExportService / OvertimeReportExcelExporter, VacationExcelExporter, AdminSalaryRequestExcelExporter. Overtime export passes only the period, so copying it directly would not preserve allocation search/filters.

Installed RevoGrid default: ExportFilePlugin only implements CSV. It reads getVisibleSource (filtered/trimmed rows excluded, not only viewport pixels), column property values and column names; it does not call cellTemplate/groupCellTemplate/columnTemplate. CSV special-cases synthetic grouping rows and writes only getGroupingName. This loses custom group summaries and, critically, actual terminal values represented by synthetic groups in allocation analytics. Collapsed children may be excluded. beforeexport permits replacing the data, but an application-specific export model would still be required, and CSV does not provide XLSX number formats, outlines, styles or freeze panes.

Implemented contract:
- A real XLSX generated by the backend, using the existing export/download architecture and existing POI capability; no new frontend XLSX dependency or RevoGrid export integration.
- Agreed flat Analytics sheet: Business account, Project, Workstream, Employee, Email, Current project role, Year total, January through December. One row per employee/project/workstream. No grouping rows, subtotals or merged data cells; users can create their own pivots. Include all authorized annual rows, auto-filter and a frozen header.
- Store numbers as numbers. For percentages store percent/100 with Excel percentage formatting; for person-months also store percent/100 with ordinary numeric formatting. Thus 100 percent is 100% or 1; a full year is 1200% or 12. Preserve absent values as blank and explicit zero as zero; calculate annual values before rounding. Group formulas must exclude nested subtotals if formulas are used, to avoid double counting.
- Reuse allocation read authorization. GET /api/v1/resource-allocations/analytics/{year}/export with unit only. Ignore UI search, business-account/project filters, hierarchy mode, group totals and expanded state. Backend obtains the full authorized annual snapshot. No selected-row payload or duplicated frontend search logic is needed.
- Use a JXLS template following overtime and salary exports. A flat repeating row makes a programmatic hierarchical exporter unnecessary. The agent can create the XLSX template; no manual template preparation by the user is needed.

Verified existing export parameter scope following user correction: overtime and salary requests pass only period, vacations pass years, assessments pass no UI filters, employee export passes includeFired, junior registry passes includeGraduated. The earlier proposal to preserve all frontend filters was unnecessarily broad and has been removed.

Implemented in analytics: year and unit query parameters (unit=percent or unit=personMonths), defaulting to current year/person-months. Local controls update the URL while preserving unrelated parameters; route changes restore values. Year changes reload data, unit changes do not. Watchers are scoped to the analytics route to avoid interfering with navigation from cached views. A request sequence guard prevents an older year response from replacing newer data. Added an unrun unit regression; git diff --check passed.

Implemented backend controller/service/exporter, real JXLS XLSX template, frontend download service and toolbar button with duplicate-request protection and error handling. Export rendering runs on boundedElastic; allocation read authorization is reused.

Added backend tests for actual template rendering in both units, numeric annual totals, zero versus missing cells, separate workstream rows, formula-like text, empty years, denied access and invalid units. Added frontend regression for export arguments, duplicate downloads and failure recovery. Tests, builds and application starts remain unrun at the user's request. Template ZIP/XML structure inspected; actual JXLS rendering and opening in Excel remain to be verified by running the supplied tests/manual download. Task retained pending user acceptance.
